# AI-TextSummarizer

🤖 A smart text summarization tool that leverages deep learning and NLP to generate concise summaries from lengthy documents.

## Features
- 🧠 Uses transformer models (e.g., BART, T5, GPT)
- 📄 Supports plain text, articles, or uploaded documents
- 🔍 Extractive or abstractive summarization modes
- 🖼️ Easy-to-use interface (Tkinter / Streamlit / Notebook)
